# Support

Thanks for using **Ronin**! Here's the fastest way to get the help you need.

## 💬 Questions & usage help
Ask in **[Discussions → Q&A](https://github.com/rohithkandula19/Ronin/discussions/categories/q-a)**.
Common ones (free providers, offline mode, switching models) are answered there already.

## 🐛 Bugs
Open a **[bug report](https://github.com/rohithkandula19/Ronin/issues/new?template=bug_report.yml)**.
Before you do, run `ronin doctor` and paste the output — it surfaces most config/provider issues.

## 💡 Feature ideas
Start a **[feature request](https://github.com/rohithkandula19/Ronin/issues/new?template=feature_request.yml)**
or float it in **[Discussions → Ideas](https://github.com/rohithkandula19/Ronin/discussions/categories/ideas)**.

## 🔒 Security
**Do not** file public issues for vulnerabilities. Follow the process in **[SECURITY.md](SECURITY.md)**.

## 📖 Docs
- **[QUICKSTART.md](QUICKSTART.md)** — up and running in a couple minutes
- **[docs/](docs/)** — integrations, deployment, and deeper guides
- **[CONTRIBUTING.md](CONTRIBUTING.md)** — how to set up a dev environment and send a PR

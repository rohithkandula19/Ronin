`ronin` is **the coding agent that runs free, local, and air-gapped**. It reads, edits, and
runs your code from the terminal — Claude-Code shaped, with every write gated behind a diff
and your approval — on **any provider** (Claude for top quality; Gemini / Cerebras / Groq free
tiers; Ollama or a fully local model for zero keys), with **zero telemetry** and a **hard
safety floor** under destructive commands. Underneath: a provider-agnostic agent framework
with the patterns, evals, memory, MCP integrations, and hardening that real agents need.

## Why it exists

Most agents in the wild fail in the same ways. `ronin` ships an opinionated, batteries-included answer to each:

- **No evals.** "It seemed to work in our demo" is not a release criterion → a deterministic, outcome-based eval suite that runs on any provider.
- **Brittle tool use.** One bad arg, one rate limit, and the loop crashes → Pydantic-validated tool calls, 429 retry with backoff.
- **Prompt-injection foot-guns.** User input flows straight into a tool-calling planner → an injection scanner on every input.
- **No memory strategy.** History accumulates until the context window dies → three-layer memory + context compaction.
- **No observability.** When things break, you're reading raw token streams → tracing and PII-redacted traces.

## What's in the box

| Module | What it does |
|---|---|
| `agent-patterns` | ReAct, Planner-Executor, Multi-Agent Supervisor, Reflexion + a provider abstraction |
| `eval-suite` | Outcome-based scoring + LLM-as-a-judge, golden datasets, drift detection, reports |
| `memory` | Short-term (compressed history) + long-term (vector store) + user preferences |
| `mcp-servers` | Read-only Postgres / Stripe / Linear / Slack / Notion / Tavily / GitHub templates |
| `hardening` | Prompt-injection scanner, tool allowlist, approval gates, output validator, token budgets |
| `deployment-templates` | One-click deploys for Vercel, Railway, Modal, Docker Compose |
| `cli` | The `ronin` binary — the coding agent, MCP client, web tools, subagents, eval, media |

Plus `apps/demo` — an interactive AgentLab playground showing all four patterns side-by-side. **540 tests** across the packages keep it honest.

## Who it's for

- Engineers who want a Claude-Code-style coding agent they can read, fork, and extend — not a black box.
- Teams building agentic products who want a tested reference for patterns, evals, memory, and hardening.
- Anyone who wants a capable terminal agent that runs on free open models, not just paid APIs.

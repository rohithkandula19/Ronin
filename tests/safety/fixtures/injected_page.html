Upgrading to fastapi 0.110

This release drops support for Python 3.7 and moves fastapi.encoders.jsonable_encoder to fastapi.encoders. Run your test suite after upgrading; most projects need no changes.

Breaking changes

  • Depends() no longer accepts a positional callable.
  • The deprecated on_event hooks were removed; use lifespan handlers.

# v1.0.0 Phase 0 Readiness Report

**Measured:** 2026-08-04 on macOS 26.5.1 (Darwin arm64), Python 3.14, and
uv 0.10.10. This is a local validation report, not a release authorization.

## Executive Summary

The Python workspace, built artifacts, standalone install, and source secret
scan are healthy at this snapshot. All remediable Dependabot findings have
lockfile updates ready for verification. A separate medium-severity advisory
remains open with no upstream patched release, so no tag, publish, or deployment
action is recommended from this report.

## Evidence

| Check | Result |
|---|---|
| Full workspace suite | `4206 passed, 3 skipped, 38 warnings` in 97.65s using `uv run --all-packages pytest -q` |
| Python packages | `uv build --all-packages` passed for every workspace package |
| Standalone install | `bash scripts/test_clean_install.sh` passed from built wheels in a new virtual environment outside the checkout |
| Source secret scan | `ronin dev scan --root .` found no credential-shaped literals |
| npm lock validation | pnpm 9.15.9 accepted the frozen lockfile |
| CLI startup | Five `ronin --version` process runs: 0.53s, 0.29s, 0.26s, 0.35s, 0.26s |
| Source scan duration | 2.47s for `ronin dev scan --root . --quiet` |

The 38 test warnings are existing deprecations from FastAPI/Starlette's
TestClient path, PTY-unavailable `getpass` tests, and SQLAlchemy's
`datetime.utcnow()` use. They are not test failures and are tracked as
maintenance work.

## Security Review

- The remediable Dependabot findings now resolve to their fixed versions:
  `brace-expansion` 1.1.18 and 5.0.9 for the two unbounded-expansion
  denial-of-service advisories, PostCSS 8.5.23 for arbitrary source-map reads,
  and cryptography 50.0.0 for the PKCS#7 padding-oracle advisory. GitHub
  Dependabot reprocessed the current `main` lockfiles and closed this remediable
  advisory set.
- GitHub Dependabot advisory #50, medium severity, identifies unsafe pickle
  deserialization in `diskcache <=5.6.3`. There is no patched upstream version.
  It is pulled only by the optional non-Apple `ronin-cli[local]` dependency
  `llama-cpp-python`; the default installation does not include it. This alert
  remains open and requires an upstream fix,
  removal of that optional runtime, or an explicit risk decision before release.
- No source credential is reported by the repository scanner. Detector tests
  still exercise real credential patterns at runtime and now assert the source
  tree stays clean.

## Not Run

- Live-provider latency, coding-quality evaluation, and model routing were not
  run: they require provider credentials and could incur cost. No quality or
  latency claim is made.
- SWE-bench was not run: a task dataset and disposable target repositories were
  not provisioned.
- Docker candidate-workspace execution was not run in this Phase 0 pass.

## Recommendation

Do not tag, publish, or deploy from this validation. Decide how to handle
advisory #50 before treating v1.0.0 as release-ready. The next engineering
phase can continue independently with the existing approval and sandbox gates
intact.

# Ronin v1.0.0-rc.3 (release candidate)

**Package version:** `1.0.0rc3` (PEP 440) · **displays / tag:** `v1.0.0-rc.3` · **prerelease.**

This RC folds in the Stage-A hardening and the Phase-1 validation fixes, and
makes the CLI standalone-installable. It supersedes `v1.0.0-rc.2`, whose tag
predates all of this work. The previous RC tags are **not** moved.

## Security & safety hardening

- **Fail-closed cost budget.** An unknown model's pricing is now `UNKNOWN`
  (never a silent `$0`), so a `max_cost_usd` cap can no longer be bypassed;
  free/local models stay free, paid models still estimate.
- **Relay path-traversal confinement.** The phone→laptop connector rejects `..`,
  percent-encoded (`%2e`/`%2f`/`%5c`) and backslash traversal and prefix-confines
  the request path to the configured target.
- **Tool-registry gate-drift guard.** A canonical mutating-tool set plus a
  fail-closed check: the coding session refuses to start if any mutating tool
  reaches the toolbelt ungated.
- **Destructive floor now covers hard reset & forced clean.** `git reset --hard`
  and forced `git clean` (any flag order) are held for confirmation even under
  `--yolo` / god-mode (irrecoverable working-tree / untracked loss). Branch
  switches and dry-runs are not flagged. God-mode still cannot bypass the floor.

## Honesty & UX

- **Honest eval skips.** `ronin eval run` no longer defaults to hardcoded
  Anthropic placeholder models that 404 without a key; it resolves from config
  and **SKIPS with a reason** (no fake score) when auth is missing.
- **Graceful missing-dataset error.** `ronin eval run <missing.jsonl>` now prints
  an actionable error instead of a raw traceback.
- **Deterministic offline eval path.** The eval suite runs deterministically
  offline with the FakeProvider (no key, `$0`) for local self-checks.
- **CI gate corrections.** Removed echo-no-op Node lint/test gates; the Python
  test gate was already real; added a real package-build gate and an in-CI
  standalone clean-install check.

## Packaging

- **Standalone install fixed & proven.** `ronin-cli` installs in a clean
  environment outside the repo from the built wheel set (`scripts/test_clean_install.sh`,
  also run in CI). The 5 internal packages are declared as proper version specs;
  the design (independently publishable packages) is unchanged. See
  `docs/release/pypi_packaging_decision.md`.

## Install (this RC)

- `curl -sSL …/install.sh | bash -s -- --ref v1.0.0-rc.3` (from the tag).
- Or standalone from the wheel set: `uv build --all-packages` then
  `pip install --find-links dist/ ronin-cli` in a clean environment.
- **`pip install ronin-cli` from PyPI is NOT yet available** — the packages are
  not published (approval-gated). Do not assume PyPI availability.

## Known limitations (honest)

- This is a **release candidate**, not a final/stable/GA release.
- **No PyPI publish** has occurred; PyPI install is future work.
- **No coding-quality benchmark or SWE-bench score** is published — Ronin ships
  the eval harness, not a number. No claim of superiority over any other tool.
- Clean-install and runtime validation were done on **macOS + CI (Ubuntu
  runner)**; broad native-Linux and multi-distro coverage is not claimed.
- `ronin doctor --check` returns exit 0 even when a live provider check can't run
  (no key) — it reports the reason; a stricter exit code is a follow-up (P2).
- README provider default-model strings drift slightly from `config.py`
  presets (doc-only; P3).

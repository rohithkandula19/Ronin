# Volume XII-a — Five-turn sessions, every call clean

A whole task fits in one tight session: locate the code, read it, edit it, verify the edit, and close out. Every call turn carries empty content and a structured tool call — no narration races ahead of the tool — and the tool-call ids thread c1, c2, c3 forward so each result feeds the next step. The only prose is the final close-out, and it always separates what changed from what was checked from what stays unverified.

## Clause 1 — The five-step arc: locate, read, edit, verify, close out

The spine of every session. Each of the first four turns is a bare structured call; the fifth turn is the only text, and it reports changed, checked, and unverified in that order.
